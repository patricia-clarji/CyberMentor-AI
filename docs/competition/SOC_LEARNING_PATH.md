# Junior SOC Analyst Learning Path

## Scope and status

The learner path is a private-beta, defensive learning sequence. It does not replace the 12-course published catalogue or expand the Harbor Light flagship mission.

- Path ID: `junior-soc-analyst-pathway`
- Content version: `1.0.0`
- Review state: `internally-checked-pending-external-review`
- Required module count: 8
- Completion: every required lesson, practice, and module assessment; no decorative percentage is used as the authority

## Ordered modules

1. SOC foundations and evidence reasoning
2. Networking, DNS, and HTTP evidence
3. Linux and Windows host evidence
4. Identity events and phishing analysis
5. SIEM query reasoning and alert triage
6. Evidence preservation, severity, and escalation
7. Incident reporting and reproducibility
8. Flagship mission preparation

The modules cover cybersecurity/SOC foundations, network evidence, DNS, HTTP, Linux navigation/processes/permissions/logs, Windows processes/events, authentication, email/phishing, indicators, SIEM reasoning, triage, severity, preservation, escalation, reporting, and mission preparation.

## Required lessons

Each module currently has one substantive required lesson:

- `soc-01-l1` — From events to defensible SOC decisions
- `soc-02-l1` — Correlating DNS and HTTP evidence
- `soc-03-l1` — Read-only host investigation
- `soc-04-l1` — Phishing as a multi-source investigation
- `soc-05-l1` — Queries that test a hypothesis
- `soc-06-l1` — Preserve first, then escalate clearly
- `soc-07-l1` — A report another analyst can reproduce
- `soc-08-l1` — Mission readiness: decide, preserve, explain

Every lesson declares objectives, linked skills, review state, version, references, why the topic matters, a conceptual explanation, synthetic evidence, a worked example, terminology, a misconception, guided practice, practical relevance, and reflection.

## Progression

Modules expose their prerequisite state honestly. A learner may preview later material, but the roadmap continues to identify incomplete prerequisite work. Module completion requires:

- all required lessons marked complete;
- all required deterministic practices passed;
- the versioned module assessment passed at 70% or above.

After all modules meet those rules, the pathway enrollment becomes complete. The flagship mission remains a separate existing assessed experience.
