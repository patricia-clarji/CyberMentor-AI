# Content authoring

Lessons are researched and written by accountable human authors. Do not ask a model to generate a course or lesson corpus. A model may assist with bounded editing or brainstorming only when that use is disclosed with `DRAFT — AI-ASSISTED — NOT REVIEWED`, independently checked, and never treated as evidence.

Start with claims, not prose. Register an authoritative public source, retrieve it with the content pipeline, and create small factual claims with precise locators and evidence excerpts. Synthesize in original language; never reconstruct proprietary courses, certification questions, paywalled material, or source pages. Keep quotations short and respect each source’s reproduction policy.

Commands must include a repeatable verification artifact or point to exact official documentation. Offensive material requires explicit authorization, local isolation, defender visibility, detection, remediation, verification, reporting, and cleanup. Assessments must test the stated objectives without exposing answer keys to the client.

Authors use concept → mental model → guided example → safe practice → check → lab → scenario → assessment → project → reflection → evidence. Distinct accountable reviewers cover cybersecurity subject matter, instructional design, accessibility, and licensing. Dual-use material also requires a distinct safety reviewer, and publication requires an authorized publisher who is not the author. No author or AI system can satisfy its own review gate.

See [the ingestion and publication workflow](ingestion-pipeline.md) for schemas, commands, validation, versioning, and publication gates.
